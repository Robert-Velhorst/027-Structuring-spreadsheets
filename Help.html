🛠️ Sheet Shaper Help

Sheet Shaper provides powerful data transformation tools directly within Google Sheets. Here's how to use each feature:

Smart Trim

Removes leading and trailing whitespace from all text cells and collapses multiple spaces into single spaces. Perfect for cleaning up imported data.

Remove Duplicates

Removes rows that are exact duplicates based on all column values. The first occurrence of each unique row is preserved.

Change Case

Convert text to different cases:

  • UPPERCASE: ALL TEXT BECOMES UPPERCASE
  • lowercase: all text becomes lowercase
  • Title Case: First Letter Of Each Word Is Capitalized
  • Sentence case: Only the first letter is capitalized

Split Text

Split text in a column using a delimiter (comma, space, etc.) and create new columns for each part. Useful for separating names, addresses, or other combined data.

Remove Empty Rows/Columns

Clean up your sheet by removing rows or columns that are completely empty or contain only whitespace.

💡 Tip: Always work on a copy of your data or create a backup before performing bulk operations. You can duplicate your sheet by right-clicking on the sheet tab.
⚠️ Important: Sheet Shaper operations cannot be undone using Ctrl+Z. Make sure you're satisfied with the results before proceeding with additional operations.

Getting Started

  1. Select the sheet you want to work with
  2. Choose a function from the "Sheet Shaper" menu
  3. Follow any prompts for additional options
  4. Review the results and continue with other operations as needed

Best Practices

  • Test operations on a small dataset first
  • Keep headers in the first row for better organization
  • Use descriptive column names
  • Regular data cleaning improves analysis accuracy
